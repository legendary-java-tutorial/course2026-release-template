# Release Day — стартовое приложение модуля 6

Node.js-приложение курса Docker 2026: страница с приветствием и счётчиком посещений.

- **Порт:** 3000.
- **Маршруты:** `/` — приветствие и число посещений; `/crash` — завершает процесс кодом 1 (для опытов с политикой перезапуска).
- **Данные:** счётчик хранится в `/data/counter.txt` — подключите к `/data` именованный том, иначе счётчик пропадёт вместе с контейнером.
- **Сборка образа:** `.github/workflows/build.yml` — запуск по метке git `v*`, образ под `linux/amd64` и `linux/arm64`. Перед первой меткой впишите во вход `images` своё пространство имён Docker Hub и создайте секреты `DOCKERHUB_USERNAME` и `DOCKERHUB_TOKEN` в настройках своего репозитория.

Запуск без Docker Hub:

```bash
docker build -t app:dev .
docker run -d -p 8080:3000 -v data:/data --name app app:dev
```
